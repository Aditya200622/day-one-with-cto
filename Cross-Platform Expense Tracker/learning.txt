19. const

const compile-time constant object/value ke liye use hota hai jab possible ho.

Flutter me common:

const Text("Hello")

Fixed UI values ke liye.

Rough rule:

Fixed/constant → const useful
Changing data  → const nahi
20. super.key
const MyApp({super.key});

key Flutter widget identity/element tracking ke liye use ho sakti hai.

super.key ka meaning:

Parent class ke key parameter ko directly forward karo.

Expanded old-style understanding:

const MyApp({Key? key}) : super(key: key);

Modern Dart syntax:

{super.key}

shorter hai.

21. {} in constructor

Example:

}
