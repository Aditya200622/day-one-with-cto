14. useState kya hai?

Sabse important current concept:

useState React component ki changing information ko store aur update karne ka mechanism hai.

Example:

const [count, setCount] = useState(0)

Isme 3 parts hain:

useState(0)
    ↓
initial value = 0

count
    ↓
current value

setCount
    ↓
value update karne wala function
15. count
const [count, setCount] = useState(0)

count current state value hai.

Initially:

count = 0
16. setCount
setCount(1)

state ko update karta hai.

Example:

setCount(count + 1)

Agar:

count = 0

to:

setCount(0 + 1)

aur new value:

count = 1
17. Normal variable vs State

Normal variable:

let count = 0

sirf normal JavaScript data hai.

React state:

const [count, setCount] = useState(0)

me React ko state change ka pata hota hai.

Flow:

setCount(...)
     ↓
State changes
     ↓
React re-renders component
     ↓
UI updates

Ye React ka core concept hai.

19. Component kya hai?

React component ek reusable UI unit hai.

  return <h1>Expense Tracker</h1>

<Header />

use kar sakte ho.

20. JSX kya hai?

React me:

return (
  <div>
    <h1>Hello</h1>
  </div>
)

ye normal HTML nahi hai.

Ye JSX hai.

JSX = JavaScript syntax extension jo UI ko declarative form me describe karne deta hai.

21. JSX aur HTML me difference

HTML:

<div class="hero">

JSX:

<div className="hero">

JSX me JavaScript expressions {} ke andar use kar sakte ho.

Example:

const name = "Aditya"

return <h1>Hello {name}</h1>

Output:

Hello Aditya
22. JSX expression {}

Example:

<img src={reactLogo} />

Yahan:

{reactLogo}

JavaScript variable ko JSX ke andar use kar raha hai.

Similarly:

<h1>{count}</h1>

state value UI me show kar sakta hai.

23. return

React component:

function App() {
  return (
    ...
  )
}

return batata hai:

Component ko UI me kya render karna hai.

24. React re-render

Suppose:

const [count, setCount] = useState(0)

UI:

<h1>{count}</h1>

button:

<button onClick={() => setCount(count + 1)}>
  Increase
</button>

Flow:

Click
 ↓
onClick
 ↓
setCount(...)
 ↓
state changes
 ↓
React re-renders
 ↓
new count appears
25. onClick

React button:

<button
  onClick={() => setCount(count + 1)}
>
  Increase
</button>

onClick event handler hai.

Meaning:

User click kare to ye function run karo.

26. Arrow function
() => {
  ...
}

JavaScript arrow function syntax hai.

Example:

() => console.log("Hello")

Button me:

onClick={() => setCount(count + 1)}

ka meaning:

click hone par ye function execute karo.
